# Forecasting Spare Parts Demand Using Machine Learning

Open Notebook on NB Viewer : https://nbviewer.org/github/uniyalayus-byte/Forecasting-Project/blob/main/Notebook/Final%20Client%20Project.ipynb

## Project Overview

This project focuses on forecasting spare parts demand using historical service and inventory data. The objective is to build a predictive analytics solution that helps organizations optimize inventory management, reduce stock shortages, and improve operational efficiency.

The project involves data preprocessing, exploratory data analysis (EDA), visualization, feature engineering, and machine learning model development to identify demand patterns and forecast spare part requirements.

---

## Business Problem

The business case is on the inventory management. Keeping Inventory of spare in various service centre to the market demand is always a challenge as most service centres spends significant amountin spare parts inventory costs. In spite of this, availability of spare parts is been one of the problem areas. 
Poor inventory planning can lead to:

* Excess inventory holding costs
* Stock shortages
* Delayed service operations
* Increased operational expenses

The goal of this project is to use data-driven forecasting techniques to improve spare parts demand prediction and support efficient inventory management.
